# 単語帳

スマホで使える、ブラウザ完結の単語帳アプリです。カードをめくって「思い出せた／思い出せなかった」を選ぶだけで、忘れかけたタイミングで復習が出る仕組み（間隔反復）になっています。

**アプリを開く：https://setuna-05.github.io/English-word/**

現在は **日常英単語・配信ゲーム・配信日常の英単語**（初期データは10語）を収録した英単語帳として動いていますが、**分類は自由に増やせる**ので、単語データを入れ替えれば、資格試験の用語、専門用語、他言語の単語など、あらゆる「単語・用語の学習アプリ」としても使えます。

> **このアプリは Claude（Anthropic 社の AI）によって生成されました。**

## 特長

- **1画面で完結するスマホ向けUI**：カードをタップして裏返し、下のボタンで答え合わせ
- **間隔反復（5段階の箱）**：思い出せたら箱が1つ上がり、次の復習が遠くなる
  - 箱2 = 1日後 / 箱3 = 3日後 / 箱4 = 7日後 / 箱5 = 14日後
  - 思い出せなかった単語は箱1に戻り、同じセッション内でもう一度出る
  - 再挑戦で思い出せた単語は、翌日にあらためて復習
- **分類を自由に追加**：単語の追加画面・一括取り込みから、好きな名前の分類を作れる
- **新しい単語は分類ごとの割合で出題**：初期設定は1セッション10語（日常英単語 6 : 配信ゲーム 2 : 配信日常 2）。割合と語数はアプリ内で変更可能
- **単語の追加・編集・削除**、検索、分類での絞り込み
- **選択削除・一括削除**：チェックで複数選んで削除、表示中の単語を全選択して削除、No.（`3, 5, 10-15` のような範囲指定も可）を指定して削除
- **一括追加**：Excel（.xlsx）・CSV・貼り付けテキストから取り込み
- **書き出し／読み込み**：単語データ・分類・出題の設定・進捗をテキストで保存・復元
- ライト／ダーク表示、PWA対応（ホーム画面に追加して使える）
- サーバー不要。データはブラウザ内（localStorage）に保存されます

## 使い方

1. [アプリ](https://setuna-05.github.io/English-word/)をブラウザで開く（スマホなら「ホーム画面に追加」するとアプリのように使えます）
2. 「学習」タブでカードをタップして答えを見る
3. 「思い出せた」「思い出せなかった」を選ぶ
4. 「単語」タブで単語の追加・編集、「データ」タブで進捗の確認・出題の設定・書き出し

進捗はブラウザに保存されるため、ブラウザのデータを消すと失われます。定期的に「データ」タブで書き出しておくと安心です。

### 単語を削除する（選択削除・一括削除）

「単語」タブで、複数の単語をまとめて削除できます。

1. 検索欄の横の **「選択」** を押して、選択モードにする（もう一度押すと「終了」して通常に戻ります）
2. 削除したい単語をタップしてチェックする。次の方法も使えます
   - **「表示中を全選択」**：今の絞り込み・検索結果に出ている単語をすべて選択（例：分類「配信ゲーム」だけ、「sus」を含む単語だけ、など）
   - **「No.で選ぶ」**：No.を入力して選択に追加。カンマか空白で区切り、範囲は `10-15` のように書けます（例：`3, 5, 10-15`）。全角数字も使えます
   - **「解除」**：選択をすべて外す
3. **「選択を削除」** を押す。ボタンが「もう一度押すと○語を削除」に変わるので、もう一度押すと削除されます

- 選択中の語数は画面上に表示されます。選択を変えると、削除の確認はやり直しになります
- 削除した単語は元に戻せません。心配なときは、先に「データ」タブで書き出しておいてください
- 削除してもNo.は詰め直されません。連番にしたいときは「データ」タブの「No.を1から振り直す」を使います
- 1語だけ削除したいときは、通常モードで単語をタップして編集画面の「削除」を使えます

## 英単語以外の学習アプリとして使う

たとえば次のような用途に使えます。

- 資格試験の用語（基本情報技術者、簿記、医療用語 など）
- 仕事・業界の専門用語
- 外国語の単語（意味の欄に日本語訳、例文の欄に用例）
- 歴史の年号・人物、化学の元素など、暗記全般

### 分類を増やす・設定する

- **単語を1つずつ追加するとき**：追加画面の「分類」で「＋新しい分類を作る」を選び、名前を入力します
- **一括で取り込むとき**：ExcelやCSVの「分類」列に新しい名前を書くだけで、自動で分類が作られます（大文字小文字だけ違う名前は、既存の分類にまとめられます）
- **出題の割合・1セッションの新しい単語数・分類名の変更**：「データ」タブの「出題の設定」で変更できます（0にすると、その分類の新しい単語は出なくなります。復習の単語には影響しません）
- 分類名は30文字までです。単語が1つもなくなった分類は、一覧から自動で消えます

## AIでExcelファイルを作る方法

ChatGPT や Claude などのAIに頼むと、このアプリにそのまま取り込めるExcelを作れます。

### Excelの形式

- 1行目（見出し行）の **A列に `No.`** と書く。この行の次の行から読み込まれます
- 列は A〜G の7列で、順番は固定です

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| No. | 分類 | 単語 | 意味 | 例文 | 例文の訳 | 覚え方 |
| 103 | 配信ゲーム | latency | 遅延、待ち時間 | High latency makes the game lag. | 遅延が大きいとゲームがラグくなる。 | 「レイテンシー」。データが届くまでの待ち時間。 |

- **No.**：空でも構いません。取り込み後、No.は1から順に自動で振り直されます。**分類と単語が同じ**（大文字小文字は区別しません）単語は、内容を更新します（進捗は残ります）
- **分類**：自由な名前を付けられます。まだない名前は、新しい分類として自動で追加されます
- **単語・意味・分類**：必須。例文・例文の訳・覚え方は空でも取り込めます（英語以外の学習では、例文の列を用例や補足に使えます）

### AIへの依頼文（コピーして使えます）

```
単語学習アプリに取り込むExcelファイル（.xlsx）を作ってください。

【テーマ】（例：家具の英単語）
【分類名】（例：日常英単語）
【語数】（例：30語）
【レベル】（例：初級〜中級）

【形式】
- 1行目は見出し行で、A列から順に
  No. / 分類 / 単語 / 意味 / 例文 / 例文の訳 / 覚え方
- No.は 1 から連番
- 分類はすべて上の【分類名】にする
- 例文は実際の場面で使われる自然な文にする（不要なら空欄）
- 覚え方は語源やイメージなど、日本語で1〜2文
- 1つのセルに改行は入れない
```

ファイルを作れないAIの場合は、「CSV形式でコードブロックに出力してください」と頼み、出力を貼り付けて取り込めます。

### アプリへの取り込み

1. 「単語」タブの **「一括」** を押す
2. **「Excel / CSVファイルを選ぶ」** でファイルを選ぶ（または、行を貼り付けて「取り込む」）
3. 「追加 ○ 件、更新 ○ 件」と表示されれば完了（新しい分類が作られたときは、その名前も表示されます）

> 取り込めなかった行は、行番号と理由が表示されます（単語や意味が空、など）。AIが作った内容は誤りを含むことがあるため、**意味や例文は取り込む前に確認してください。**

## カスタマイズ

アプリ内で変えられるもの（分類・出題の割合・語数・表示テーマ）は「データ」タブから変更できます。コードを編集する場合は、`index.html` の次の部分です。

- 初期データ：`INITIAL_WORDS`（初回起動時にだけ読み込まれます）
- 初期の分類と割合：`DEFAULT_CATS`（日常英単語・配信ゲーム・配信日常）、`DEFAULT_MIX`、`DEFAULT_PER_SESSION`。単語が1つもない分類は一覧に出ません
- 復習の間隔（日数）：`INTERVALS`
- 分類の色：CSSの `--c0`〜`--c7`（8色。分類が8つを超えると色は繰り返します）

## ファイル構成

- `index.html`：アプリ本体
- `manifest.webmanifest`、`icon-192.png`、`icon-512.png`、`icon-maskable-512.png`、`sw.js`：ホーム画面への追加・オフライン用
- `xlsx.full.min.js`：Excel取り込み用ライブラリ
